# Changelog

## 0.1.0

- First release candidate. Forge Trigger becomes its own package (`NAinfini.ForgeTrigger`) and registers provider `forge.module.trigger` through the public Forge Runtime registration entry instead of being compiled into the host. This version ships the `evaluate` binding for `forge.condition.predicate.compare` and no other capability.
- Release candidate only: not published, not installed as a package, offline validation only.
