# Changelog

## 1.0.0

- First release candidate of `NAinfini-ForgeEnemy`: the native plugin registers provider `forge.module.gtfo.enemy` with its damage, heal and health-change bindings, the enemy spawn requirement source and the native observation hooks. The package ships the native plugin only; the game-independent `ForgeEnemy.dll` stays out of the archive.
- Release candidate only: not published, not installed as a package, offline validation only.
