**[English](#en)** · **[中文](#zh)**

<a id="en"></a>
## English

This repository holds the standalone GTFO QoL mod [InfiniTweaks](InfiniTweaks/README.md).

The Forge base packages (ForgeRuntime, ForgeTrigger, ForgeMap, ForgeEnemy, ForgeWeapon,
ForgeDevelopment) and the release tooling moved to
[NAinfini/GTFO-Forge](https://github.com/NAinfini/GTFO-Forge) under `Mods/`, together
with their full history. Forge plans, code and issues live there.

InfiniTweaks does not reference any Forge assembly. Build and test commands are in its
[README](InfiniTweaks/README.md).
